# **Ejercicio 8**

## Explicacion

En este ejercicio encontramos una clase estudiante con un constructor definido que, ademas de agregar el nombre del estudiante, inicializa un arraylist de calificaciones. Tenemos un getter que devuelve el nombre del estudiante. Luego tenemos un metodo agregarNota que recibe un parametro nota y verifica que se encuentre entre el rango de 0.0 y 10.0 para luego agregarlo al arraylist de calificaciones y devuelve un mensaje exitoso o de error. Tambien, encontramos un metodo calcularPromedio que no recibe parametros, se crean dos variables dentro del metodo que se utilizaran mas tarde para poder devolver el promedio, un contador de notas y una suma de todas las notas del arraylist. Por ultimo, el metodo haAprobado que no recibe parametros, este llama al metodo calcular promedio y verifica, si devuelve 6.0 o mayor, el metodo devuelve true. En caso contrario, devuelve false.
