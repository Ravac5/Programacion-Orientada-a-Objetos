# **Ejercicio 7**

## Explicacion

En este ejercicio encontramos una clase cuentaBancaria la cual tiene dos constructores, uno que recibe el titular de la cuenta y el saldo y otro que solo recibe el titular. Luego tenemos los metodos getters para el titular y el saldo. Tambien, encontramos un metodo depositar que recibe un saldo y verifica que sea mayor a cero para luego sumarlo al saldo de la cuenta. El ultimo metodo es el de retirar y recibe un monto, este metodo primero verifica que el monto solicitado sea menor o igual al saldo de la cuenta y si esto se cumple lo resta.
